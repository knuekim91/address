# 교직원 주소록 검색

이름, 과목, 주소, 전화번호로 교직원을 찾는 간단한 웹앱입니다.

## 데이터 보안

- 주소록 데이터는 이 저장소에 **포함되어 있지 않습니다.**
- 사용자가 자기 컴퓨터에 있는 JSON 파일을 직접 고르면, 브라우저 안에서만 읽습니다. 서버로 전송하거나 저장하지 않습니다.
- `.gitignore`가 데이터 파일 형식을 제외하도록 설정되어 있습니다.

## 데이터 형식

JSON 배열이며, 각 항목은 다음 필드를 가집니다.

```json
[
  {"org": "학교명", "role": "교사", "name": "홍길동", "subject": "수학",
   "phone": "053-000-0000", "mobile": "010-0000-0000",
   "address": "수성구 예시로 12", "zip": "00000"}
]
```

`sample.json`은 가짜 데이터 예시이며, 앱의 "샘플로 체험하기" 버튼에서 사용합니다.

## 실행

`index.html`을 브라우저로 열거나, GitHub Pages에 올린 뒤 주소로 접속하면 됩니다.
